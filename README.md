# Student Performance Prediction using Linear Regression

## 📌 Project Overview
This project predicts student marks based on study hours using Linear Regression.

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Algorithm Used
Linear Regression (Supervised Machine Learning)

## 📈 Evaluation Metric
Mean Squared Error (MSE)

## 🎯 Conclusion
The model successfully predicts marks based on study hours by establishing a linear relationship between input and output.
